## Descripción del proyecto
El proyecto pretende desarrollar un modelo, utilizando la ciencia de datos, capaz de predecir el rendimiento académico de los estudiantes sin grupo determinado, es decir sin especificar por una universidad, o una clase... basándose en el análisis de las variables de asistencia a clases, horas de estudio, participación en actividades académicas y calificaciones anteriores.

**Propósito**

Identificar los estudiantes que pueden presentar dificultades académicas y que factores influyen en esto para poder generar recomendaciones que contribuyan a mejorar su desempeño

***Problema a resolver***

En las instituciones educativas, sin importar que tan grandes o pequeñas sean, al ser una cantidad grande de estudiantes que no se les puede llevar control absoluto a cada uno, se detectan problemas académicos cuando ya es demasiado tarde para intervenir; además, i bien, y como lo es el caso de nuestra universidad, se informa con antelación cuando hay problemas en el promedio para tener la opción de retirar, no siempre se encuentra la raíz del problema para realmente buscar soluciones y recomendaciones para mejorar.

***Objetivos***

<details>
  
<summary> Objetivo general </summary>
Desarrollar un modelo predictivo que permita estimar el rendimiento académico de los estudiantes a partir de datos históricos, es decir, datos tomados y analizados en los que se puede encontrar una tendencia.
  
</details>

<details>
  
<summary> Objetivos específicos </summary>

1. Analizar el comportamiento de las notas de los estudiantes
2. Identificar fsctores asociados a la mejora o desmejora académica (factores influyentes)
3. Obtener indicadores a gran escala, es decir, lo suficientemente contundentes para la toma de decisiones educativas
  
</details>
